# Lokale Nachweise

Tatsächlich erstellte Bildschirmbilder, Befehlsausgaben und Abnahmeprotokolle hier ablegen. Dateien sind standardmäßig von Git ausgeschlossen. Die lokale `.gitignore` nimmt die synthetische Abnahme von P02-T01 und ihren Prüflauf ausdrücklich für die spätere Sicherung durch den Runner aus.

- `P02-T01-pruefung.json`: tatsächliche Ausgabe, Prüfergebnisse, Zeitmessung und Eingabeprüfsummen vom 1. November 2026.
- `p02-t01-pruefen.py`: wiederholbare begrenzte Abnahme; Aufruf siehe `START.md`.

Dieser Nachweis belegt keine persistente Import-Idempotenz und keine Datenbank-, API- oder Elastic-Ausführung.
